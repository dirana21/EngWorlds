# Wordly

Мінімалістичний вебзастосунок для вивчення англійських слів за допомогою карток. На лицьовій стороні показане англійське слово, на зворотній — український переклад і приблизна вимова кирилицею.

## Можливості

- переворот картки натисканням або клавішею `Space`;
- озвучування англійського слова засобами браузера;
- режим тесту з реченнями та п’ятьма випадково перемішаними варіантами відповіді;
- перемішування та скидання колоди;
- 40 слів із першого каталогу «Біологія 1»;
- перейменування каталогу зі збереженням назви у браузері;
- збереження поточного місця у браузері;
- адаптивний інтерфейс для телефону та комп'ютера;
- жодних залежностей або збірки — готово для GitHub Pages.

## Запуск локально

Відкрийте `index.html` у браузері або запустіть будь-який статичний HTTP-сервер у цій папці.

## Публікація на GitHub Pages

1. Створіть GitHub-репозиторій і завантажте туди всі файли з цієї папки.
2. У репозиторії відкрийте **Settings → Pages**.
3. У **Build and deployment** оберіть **Deploy from a branch**.
4. Оберіть гілку `main`, папку `/(root)` і натисніть **Save**.

## Як змінити слова

Відкрийте `app.js` і відредагуйте масив `originalWords` на початку файлу:

```js
{ english: "Help", ukrainian: "Допомога", pronunciation: "[хелп]" }
```
